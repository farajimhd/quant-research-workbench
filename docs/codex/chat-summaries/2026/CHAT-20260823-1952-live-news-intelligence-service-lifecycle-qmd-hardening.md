### Narrative

This chat began as the production continuation of the News Synthesis and forecast-label research completed earlier on August 23. The user initially proposed a deterministic rejection stage followed by DeepFM and a later LLM labeler, but refined the live policy during design review. The latest durable decision is that News Synthesis runs for every incoming article and remains highly visible because its structured event, issuer, source, document, concept, and evidence views accelerate reading, but none of its labels may filter News, authorize forecast eligibility, sort a decision queue, or generate a signal. DeepFM is the only live forecast-eligibility authority, with a configurable operating threshold of `0.5`. The threshold is persisted as provenance but is not shown as a table label. During the final handoff, the operating contract, AI-services guide, and Text Intelligence README were corrected so they no longer describe the superseded deterministic-first route.

The approved serving design has two LLM stages. Stage 1 is issuer-level News review: forecast relevance, issuer role and identity confidence, language sentiment, independent positive and negative implication probabilities, event tags, time scope, claim source, evidence, and review state. Stage 2 is a separately requested market-reaction hypothesis: ticker and causal context timestamp, five horizons from one minute through extended close, up/down/no-action probabilities, expected return, favorable and adverse excursion, confidence, abstention, regime compatibility, evidence, conflicts, invalidation conditions, and uncertainty. Manual mode exposes separate `Review` and `Forecast Reaction` actions. Stage 1 does not silently call Stage 2. Automatic mode is implemented through the same contracts, but both Text Intelligence and News Hypothesis launch in manual mode. When explicitly enabled, automatic results use the same persistence and Data Field path and can generate signals through configured Rule Sets.

Commit `4ae25db9` established the production funnel across Text Intelligence, Model Gateway, News Hypothesis, backend signal evaluation, and the frontend. The system pins a promoted DeepFM artifact, processes canonical source revisions idempotently, validates structured LLM responses, and stores current plus append-only issuer-review and market-hypothesis history. Provider, model, prompt, schema and contract versions, source hash, tokens, cost, latency, trigger mode, context timestamps, and failures remain durable. Causal reaction context is frozen at publication time and can include recent and current-session price action, point-in-time fundamentals, recent SEC filing titles/forms and available labels, and recent prior News. Missing context remains explicit. A broader SEC synthesis product was not invented as part of this task.

The synthesis card presents class, purpose, direction, primary concept, origin, and text coverage; detail view retains statement type, epistemic status, time relation, identity status, semantic role, discourse role, concept evidence, source-quality flags, and document envelope. Review and reaction cards show the highest-value probabilities, selected horizon, confidence, regime, status, and appropriate action without overcrowding the headline. The growing service set prompted a separate operational design. Rather than one script per workspace or service, the user wanted static groups plus a dynamic development group that restarts only running services whose effective implementation changed. Commit `617f9028` added `scripts/services.ps1`, `scripts/service_manager.py`, and `scripts/service_catalog.json`. Profiles cover the application, Historical and Live workspaces, Gateways, Market Data, Intelligence/Middleware, Documents, and all services; every service is also individually addressable. Fingerprints include owned source, shared contracts, safe environment values, launchers, and promoted model manifests, so uncommitted edits count without a version bump. `start` preserves healthy running dependencies, `restart dev` selects changed running services, `--within` bounds selection, plans are non-mutating, failed starts roll back only manager-owned processes, and foreign listeners are not adopted. QMD Live retains its explicit Laptop/Workstation role, dedicated lifecycle, and computation-target lease restoration. `docs/SERVICE_MANAGEMENT.md` is the complete operator guide. Before reboot, the intended command is `scripts/services.ps1 stop all`, followed by `status all`.

The final incident began after ClickHouse became unresponsive during QMD work and required a server restart. Read-only QMD and ClickHouse logs showed that the culprit was not normal QMD Live ingestion. QMD History `/coverage/latest` repeatedly aggregated the entire 20.8-million-row continuity table, reached 65 query starts per minute, and allowed 5-10.7 GiB executions lasting 90-142 seconds. Combined workload reached ClickHouse's 226.28 GiB global memory limit, rejected writes, and exposed a ClickHouse 26.3.12.3 segmentation fault in `MergeTreeDataPartWriterCompact::cancel()`. Commit `1c32c204` changed the endpoint to resolve the target date first and aggregate only that session, capped each query at 512 MiB, two threads, and 15 seconds, serialized cold lookup, and cached 64 results for 30 seconds. Only QMD History was restarted; QMD Live remained running. A burst of 100 simultaneous requests completed 100/100 in 384 ms while ClickHouse ran only two queries peaking at 6.53 MiB and 9.20 MiB for 7-11 ms. The application workload is bounded; the server-version crash remains an upstream defect rather than something hidden by the fix.

### Durable decisions

- News Synthesis runs on every canonical News revision and is fully presented, but is view-only for forecast eligibility and signals.
- DeepFM is the only live forecast-eligibility authority. Its configured operating threshold is `0.5`; threshold provenance is persisted but not shown in table labels.
- AI News Review and Market Reaction are separate manual actions. Automatic mode exists but launches disabled and must use the identical persisted contracts when enabled.
- All News, Scanner, Watchlist, Signal Stream, ticker surfaces, and News Detail reuse the same intelligence fields. New signal occurrences freeze matched intelligence at trigger time.
- Containers opened from Live inherit the live clock and source authority. Replay, stored Canvas clocks, and the browser clock cannot override them.
- One lifecycle manager owns routine service operations. Dynamic `dev` selection depends on effective fingerprints, not commits or version bumps.
- QMD Live restart is never implied by unrelated middleware or frontend changes. It retains explicit host role and lease restoration.
- QMD History query endpoints must be date-scoped, bounded, coalesced where appropriate, and unable to multiply full-table ClickHouse scans.
